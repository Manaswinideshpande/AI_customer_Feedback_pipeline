# AI-Driven Customer Feedback Analytics Pipeline 📊

A production-ready automation pipeline that ingests raw customer reviews, runs high-speed structured AI analysis, and visualizes operational KPIs in an interactive dashboard.

## 🚀 Features
- **Data Ingestion:** Fetches real-time comments from a REST API with resilient error handling.
- **AI Core Engine:** Powered by **Groq + Llama 3.3** to extract structured JSON (Sentiment, Severity, Topic, Summary).
- **Analytics Dashboard:** Light, responsive UI featuring live KPI metrics and dynamic Plotly charts.

## 🛠️ Tech Stack
- Python, Streamlit, Pandas, Plotly, Requests, Groq API (OpenAI SDK)
